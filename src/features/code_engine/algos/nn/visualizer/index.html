§05 · quickstart three steps · runs anywhere

Running in three
commands.

macOS, Linux & Windows · pure Python 3.10+. Zero compilation step, zero GPU driver lock-in to run scalar tests. Evaluates analytical vector-Jacobian products with machine precision.
Re-runs deterministic verification in place.

01 · install + test
$ git clone https://github.com/Chief-Strategist-J/llm-obs-infra
# zero external dependencies:
$ python3 -m unittest discover -s tests/unit/algos

One-time machine setup: executes 100% of unit tests covering DoReMi, FlashAttention, RoPE, ZeRO-3, AdamW WSD, and GRPO reasoning.

02 · execute pipeline
$ python3 -m policies.orchestrator.train --stage=01,02,03
# executes doremi mixture optimization,
# 5D parallel forward-backward VJP graph

Auto-detects model dimensions and shards column/row tensors — Megatron TP, Context Ring Attention, and ZeRO-3 Parameter Sharding.

03 · serve + verify
$ python3 -m policies.orchestrator.serve --paged --grpo
# paged-attention block tables
# step-level reasoning fallacy verifier

Engine serves continuous iteration-level batches; virtual memory fragmentation strictly bounded below 4% with Structured Grammar FSM.
