Differentiable Neural Memory

Let $\mathcal{M}_t \in \mathbb{R}^{N \times D}$ denote an external memory matrix at time step $t$ organized into $N$ addressable memory slots, each of embedding dimension $D$. A <strong>Differentiable Neural Memory</strong> controller interfaces with $\mathcal{M}_t$ using continuous, end-to-end differentiable reading and writing operations. Given a content-based query read key $\mathbf{k}_t \in \mathbb{R}^D$ and inverse temperature sharpening parameter $\beta > 0$, the controller computes normalized cosine similarity scores across memory slots: {\boldmath
◈ PRIMARY MATHEMATICAL FORMULATION & DYNAMIC FLOW KaTeX Verified · Closed-Form
$$S(\mathbf{k}_t, \mathcal{M}_t[i]) = \frac{\mathbf{k}_t \cdot \mathcal{M}_t[i]}{\|\mathbf{k}_t\|_2 \|\mathcal{M}_t[i]\|_2 + \epsilon}$$

◈ Algorithmic Execution Pipeline
ALGORITHM Differentiable Neural Memory Content Read and Gated Write
Require: Memory matrix $\mathcal{M} \in \mathbb{R}^{N \times D}$, read key $\mathbf{k} \in \mathbb{R}^D$, key sharpness $\beta > 0$, write weights $\mathbf{w}^w \in \mathbb{R}^N$ (optional), erase vector $\mathbf{e} \in [0, 1]^D$ (optional), add vector $\mathbf{a} \in \mathbb{R}^D$ (optional)
Ensure: Read vector $\mathbf{r} \in \mathbb{R}^D$, read weights $\mathbf{w}^r \in \mathbb{R}^N$, updated memory $\mathcal{M}_{\text{next}} \in \mathbb{R}^{N \times D}$, memory norm $\|\mathcal{M}_{\text{next}}\|_F$
1 $\epsilon \gets 10^{-8}$
2 $norm\_k \gets \sqrt{\sum_{d=0}^{D-1} \mathbf{k}[d]^2} + \epsilon$
3 Initialize array $\mathbf{s} \in \mathbb{R}^N$
4 for $i = 0$ \textbf{to} $N-1$} \Comment{Compute Cosine Similarities do
5 $dot \gets \sum_{d=0}^{D-1} \mathbf{k}[d] \cdot \mathcal{M}[i][d]$
6 $norm\_m \gets \sqrt{\sum_{d=0}^{D-1} \mathcal{M}[i][d]^2} + \epsilon$
7 $\mathbf{s}[i] \gets \beta \cdot (dot / (norm\_k \cdot norm\_m))$
8 $s_{\max} \gets \max_i \mathbf{s}[i]$
9 $sum\_exp \gets \sum_{i=0}^{N-1} \exp(\mathbf{s}[i] - s_{\max})$
10 Initialize $\mathbf{w}^r \in \mathbb{R}^N, \quad \mathbf{r} \in \mathbb{R}^D$
11 for $i = 0$ \textbf{to} $N-1$ do
12 $\mathbf{w}^r[i] \gets \exp(\mathbf{s}[i] - s_{\max}) / sum\_exp$
13 for $d = 0$ \textbf{to} $D-1$} \Comment{Perform Soft Read do
14 $\mathbf{r}[d] \gets \sum_{i=0}^{N-1} \mathbf{w}^r[i] \cdot \mathcal{M}[i][d]$
15 Initialize $\mathcal{M}_{\text{next}} \in \mathbb{R}^{N \times D}, \quad norm\_sq \gets 0.0$
16 for $i = 0$ \textbf{to} $N-1$} \Comment{Optional Gated Erase and Write do
17 for $d = 0$ \textbf{to} $D-1$ do
18 $v \gets \mathcal{M}[i][d]$
19 if write operations enabled then
20 $e_d \gets \max(0.0, \min(1.0, \mathbf{e}[d]))$
21 $v \gets v \cdot (1.0 - \mathbf{w}^w[i] \cdot e_d) + \mathbf{w}^w[i] \cdot \mathbf{a}[d]$
22 $\mathcal{M}_{\text{next}}[i][d] \gets v$
23 $norm\_sq \gets norm\_sq + v^2$
24 return $(\mathbf{r}, \mathbf{w}^r, \mathcal{M}_{\text{next}}, \sqrt{norm\_sq})$

★ Theoretical Guarantees & Invariant Bounds
Convex Hull Containment of the Read Vector
Let $\mathcal{M} \in \mathbb{R}^{N \times D}$ denote the memory matrix with slot vectors $\mathbf{m}_0, \dots, \mathbf{m}_{N-1}$. For any query key $\mathbf{k}$ and sharpness parameter $\beta > 0$, the synthesized read vector $\mathbf{r}$ lies strictly within the convex hull of the memory slots: $$ \mathbf{r} \in \operatorname{conv}(\{\mathbf{m}_0, \mathbf{m}_1, \dots, \mathbf{m}_{N-1}\}) $$ Consequently, $\|\mathbf{r}\|_2 \le \max_{i} \|\mathbf{m}_i\|_2$.
Non-Negativity Preservation under Bounded Erase and Add
Let $\mathcal{M}_0 \in \mathbb{R}_{\ge 0}^{N \times D}$ be non-negative. If the erase vector satisfies $\mathbf{e}_t \in [0, 1]^D$, the add vector satisfies $\mathbf{a}_t \in \mathbb{R}_{\ge 0}^D$, and write weights satisfy $\mathbf{w}_t^w \in [0, 1]^N$, then the updated memory matrix remains non-negative for all $t \ge 0$: $$ \mathcal{M}_{t+1}[i, d] \ge 0, \quad \forall i \in \{0, \dots, N-1\}, \; d \in \{0, \dots, D-1\} $$
⚙ Asymptotic Complexity & Hardware Target
▸ Time Complexity: $\mathcal{O}(N)$ FLOPs per layer forward execution.
▸ Space Complexity: $\mathcal{O}(N)$ auxiliary memory buffers for intermediate activations.
