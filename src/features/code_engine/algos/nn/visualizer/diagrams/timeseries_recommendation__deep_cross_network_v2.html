Deep Cross Network V2

Let $\mathbf{x}_0 \in \mathbb{R}^D$ denote a concatenated feature representation combining continuous dense features and categorical embedding lookup vectors. In click-through rate (CTR) and conversion modeling, learning high-order feature interactions (e.g. $\text{UserAge} \times \text{AdCategory} \times \text{Device}$) is essential. <strong>Deep \& Cross Network v2 (DCN-v2)</strong> explicitly models multi-order polynomial feature crosses without manual combinatorial feature engineering. The $l$-th <strong>Matrix Cross Layer</strong> maps feature state $\mathbf{x}_l \in \mathbb{R}^D$ to $\mathbf{x}_{l+1} \in \mathbb{R}^D$ according to: {\boldmath
◈ PRIMARY MATHEMATICAL FORMULATION & DYNAMIC FLOW KaTeX Verified · Closed-Form
$$\mathbf{x}_{l+1} = \mathbf{x}_0 \odot \left( W_l \mathbf{x}_l + \mathbf{b}_l \right) + \mathbf{x}_l$$

◈ Algorithmic Execution Pipeline
ALGORITHM Deep \& Cross Network v2 (DCN-v2) Forward Evaluation
Require: Input vector $\mathbf{x}_0 \in \mathbb{R}^D$, cross weights $W_l \in \mathbb{R}^{D \times D}$, cross bias $\mathbf{b}_l \in \mathbb{R}^D$, deep weights $W_{\text{deep}} \in \mathbb{R}^{D_{\text{deep}} \times D}$, deep bias $\mathbf{b}_{\text{deep}} \in \mathbb{R}^{D_{\text{deep}}}$, output weights $\mathbf{w}_{\text{out}} \in \mathbb{R}^{D + D_{\text{deep}}}$
Ensure: Cross output $\mathbf{x}_{\text{cross}} \in \mathbb{R}^D$, deep output $\mathbf{x}_{\text{deep}} \in \mathbb{R}^{D_{\text{deep}}}$, predicted probability $\widehat{y}$, cross energy $E_{\text{cross}}$
1 Initialize $\mathbf{u} \in \mathbb{R}^D, \quad \mathbf{x}_{\text{cross}} \in \mathbb{R}^D, \quad E_{\text{sq}} \gets 0.0$
2 for $i = 0$ \textbf{to} $D-1$} \Comment{Matrix Cross Step do
3 $\mathbf{u}[i] \gets \sum_{j=0}^{D-1} W_l[i][j] \cdot \mathbf{x}_0[j] + \mathbf{b}_l[i]$
4 $crossed \gets \mathbf{x}_0[i] \cdot \mathbf{u}[i] + \mathbf{x}_0[i]$
5 $\mathbf{x}_{\text{cross}}[i] \gets crossed$
6 $E_{\text{sq}} \gets E_{\text{sq}} + crossed^2$
7 Initialize $\mathbf{x}_{\text{deep}} \in \mathbb{R}^{D_{\text{deep}}}$
8 for $i = 0$ \textbf{to} $D_{\text{deep}}-1$} \Comment{Deep Non-Linear MLP Branch do
9 $val \gets \sum_{j=0}^{D-1} W_{\text{deep}}[i][j] \cdot \mathbf{x}_0[j] + \mathbf{b}_{\text{deep}}[i]$
10 $\mathbf{x}_{\text{deep}}[i] \gets \max(0.0, val)$
11 $\mathbf{z} \gets [\mathbf{x}_{\text{cross}}; \; \mathbf{x}_{\text{deep}}] \in \mathbb{R}^{D + D_{\text{deep}}}$
12 $logit \gets \sum_{k=0}^{D + D_{\text{deep}}-1} \mathbf{w}_{\text{out}}[k] \cdot \mathbf{z}[k]$ \Comment{Sigmoid Scoring}
13 $\widehat{y} \gets (logit \ge 0) \;?\; \frac{1}{1 + \exp(-logit)} : \frac{\exp(logit)}{1 + \exp(logit)}$
14 return $(\mathbf{x}_{\text{cross}}, \mathbf{x}_{\text{deep}}, \widehat{y}, \sqrt{E_{\text{sq}}})$

★ Theoretical Guarantees & Invariant Bounds
Polynomial Degree Growth in Matrix Cross Layers
Let $\mathbf{x}_0 \in \mathbb{R}^D$ be a vector of linear monomials (degree 1). An $L$-layer matrix cross network produces a representation $\mathbf{x}_L$ whose elements are multivariate polynomials in the input coordinates with maximum polynomial degree strictly equal to $L + 1$: $$ \operatorname{deg}(\mathbf{x}_L) = L + 1 $$
Strict Output Probability Calibration via Sigmoid Activation
For any input features $\mathbf{x}_0 \in \mathbb{R}^D$ and finite network parameters, the predicted conversion probability $\widehat{y}$ lies strictly within the open unit interval: $$ \widehat{y} \in (0, 1) $$
⚙ Asymptotic Complexity & Hardware Target
▸ Time Complexity: $\mathcal{O}(N)$ FLOPs per layer forward execution.
▸ Space Complexity: $\mathcal{O}(N)$ auxiliary memory buffers for intermediate activations.
