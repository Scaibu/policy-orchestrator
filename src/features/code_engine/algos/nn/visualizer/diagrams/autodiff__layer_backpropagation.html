◈ Algorithmic Execution Pipeline
ALGORITHM Layer-by-Layer Affine Backpropagation
Require: Inputs $\mathbf{X} \in \mathbb{R}^{B \times D_{\mathrm{in}}}$, weights $\mathbf{W} \in \mathbb{R}^{D_{\mathrm{out}} \times D_{\mathrm{in}}}$, upstream gradients $\mathbf{dY} \in \mathbb{R}^{B \times D_{\mathrm{out}}}$, activation $\mathrm{act}$, pre-activations $\mathbf{Z}$.
Ensure: Input gradients $\mathbf{dX}$, weight gradients $\mathbf{dW}$, bias gradients $\mathbf{db}$.
1 Initialize $\mathbf{\Delta} \gets [0.0]^{B \times D_{\mathrm{out}}}$
2 for $i = 1$ to $B$ do
3 for $j = 1$ to $D_{\mathrm{out}}$ do
4 $dy \gets dY_{i, j}$
5 if $\mathrm{act} = \text{linear}$ then
6 $\Delta_{i, j} \gets dy$
7 else if $\mathrm{act} = \text{relu}$ then
8 $\Delta_{i, j} \gets dy \cdot \mathbb{I}_{\{Z_{i, j} > 0\}}$
9 else if $\mathrm{act} = \text{sigmoid}$ then
10 $s \gets \sigma(Z_{i, j}), \quad \Delta_{i, j} \gets dy \cdot s \cdot (1.0 - s)$
11 else if $\mathrm{act} = \text{tanh}$ then
12 $th \gets \tanh(Z_{i, j}), \quad \Delta_{i, j} \gets dy \cdot (1.0 - th^2)$
13 $\mathbf{dX} \gets \mathbf{\Delta} \cdot \mathbf{W}$ \Comment{Shape $(B, D_{\mathrm{in}})$}
14 $\mathbf{dW} \gets \mathbf{\Delta}^\top \cdot \mathbf{X}$ \Comment{Shape $(D_{\mathrm{out}}, D_{\mathrm{in}})$}
15 $\mathbf{db} \gets \sum_{i=1}^B \mathbf{\Delta}_{i, :}$ \Comment{Shape $(D_{\mathrm{out}},)$}
16 return $\mathbf{dX}, \quad \mathbf{dW}, \quad \mathbf{db}$

★ Theoretical Guarantees & Invariant Bounds
Exact Differential Form Invariance
\label{thm:matrix_chain_rule} \textbf{Assumptions:} Let affine transformation $\mathbf{Z} = \mathbf{X} \mathbf{W}^\top + \mathbf{b}$ be continuously differentiable with scalar loss $\mathcal{L}$. \textbf{Guarantee:} The differential forms evaluate exactly as $d\mathcal{L} = \operatorname{Tr}(\mathbf{\Delta}^\top d\mathbf{Z}) = \operatorname{Tr}((\mathbf{\Delta}^\top \mathbf{X}) d\mathbf{W}^\top) + \operatorname{Tr}((\mathbf{W}^\top \mathbf{\Delta}^\top) d\mathbf{X}) + \mathbf{\Delta}^\top \mathbf{1} d\mathbf{b}$, yielding gradient expressions~\eqref{eq:grad_w}--\eqref{eq:grad_b} without approximation error. \textbf{Proof:} Substituting $d\mathbf{Z} = (d\mathbf{X})\mathbf{W}^\top + \mathbf{X}(d\mathbf{W})^\top + \mathbf{1}(d\mathbf{b})^\top$ into the trace formulation: $$ \operatorname{Tr}(\mathbf{\Delta}^\top d\mathbf{Z}) = \operatorname{Tr}(\mathbf{\Delta}^\top (d\mathbf{X})\mathbf{W}^\top) + \operatorname{Tr}(\mathbf{\Delta}^\top \mathbf{X} (d\mathbf{W})^\top) + \operatorname{Tr}(\mathbf{\Delta}^\top \mathbf{1} (d\mathbf{b})^\top). $$ Using the cyclic trace property $\operatorname{Tr}(\mathbf{A}\mathbf{B}) = \operatorname{Tr}(\mathbf{B}\mathbf{A})$: $\operatorname{Tr}(\mathbf{\Delta}^\top (d\mathbf{X})\mathbf{W}^\top) = \operatorname{Tr}(\mathbf{W}^\top \mathbf{\Delta}^\top d\mathbf{X}) = \operatorname{Tr}((\mathbf{\Delta}\mathbf{W})^\top d\mathbf{X}) \implies \frac{\partial \mathcal{L}}{\partial \mathbf{X}} = \mathbf{\Delta}\mathbf{W}$. $\operatorname{Tr}(\mathbf{\Delta}^\top \mathbf{X} (d\mathbf{W})^\top) = \operatorname{Tr}(( \mathbf{\Delta}^\top \mathbf{X} ) d\mathbf{W}^\top) \implies \frac{\partial \mathcal{L}}{\partial \mathbf{W}} = \mathbf{\Delta}^\top \mathbf{X}$. \textbf{Limitations:} Memory footprint requires caching activations $\mathbf{X}$ and $\mathbf{Z}$ across all active layers until the backward pass reaches them.
⚙ Asymptotic Complexity & Hardware Target
▸ Time Complexity: $\mathcal{O}(B \cdot D_{\mathrm{in}} \cdot D_{\mathrm{out}})$ multiply-accumulate operations for $\mathbf{dX}$ and $\mathbf{dW}$.
▸ Space Complexity: $\mathcal{O}(B \cdot D_{\mathrm{in}} + D_{\mathrm{out}} \cdot D_{\mathrm{in}} + D_{\mathrm{out}})$ for output gradient matrices.
