Phase 2: Transformer Block Micro-Architecture & Activation Dynamics

RMSNorm pre-conditions activations. RoPE rotary embeddings encode relative positions. FlashAttention tiled SRAM kernel computes softmax in O(N) HBM accesses. MoE Top-K router dispatches tokens to SwiGLU expert networks.
