◈ Internal Execution Lifecycle (9 Passes)
PASS [01] Allocate m ≥ts [-∈fty]^C, \ell ≥ts [0.0]^C, O ≥ts 0_C × d, scale ≥ts 1 / \sqrtd
PASS [02] r = 0 bfto N-1
PASS [03] K_curr ≥ts K^(r), V_curr ≥ts V^(r)
PASS [04] i = 0 bfto C-1
PASS [05] Compute chunk logits: s[j] ≥ts scale \cdot ∑_k=0^d-1 Q[i, k] K_curr[j, k] for j ∈ [0, C-1]
PASS [06] m_block ≥ts max_j s[j]
PASS [07] m_new ≥ts max(m[i], m_block)
PASS [08] α ≥ts (m[i] == -∈fty) ? 0.0 : exp(m[i] - m_new)
PASS [09] \ell[i] ≥ts \ell[i] \cdot α + ∑_j=0^C-1 exp(s[j] - m_new)

★ Theoretical Guarantees & Invariant Bounds
Bit-Level Exactness of Online Softmax Ring Accumulation
Let S = [S^(0), S^(1), ..., S^(N-1)] ∈ ℝ^C × L be the complete concatenation of attention logits across all N chunks of keys, and let V = [V^(0), ..., V^(N-1)]^T ∈ ℝ^L × d be the complete value tensor.
Zero Bubble Overhead Under Communication Compute Parity
If C ≥ \frac4 \cdot B_bytesFLOPs/byte, the communication latency of circulating key-value blocks around the ring is strictly completely hidden behind the forward attention tensor core computation.
