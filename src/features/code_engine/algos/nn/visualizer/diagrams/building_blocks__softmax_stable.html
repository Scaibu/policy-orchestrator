◈ Input Tensors & Parameter Arrays
● Logit batch Z \in \mathbbR^B \times K
● temperature T > 0
● mode \in \standard\_stable
● log\_softmax
● online\_streaming\
◈ Execution Lifecycle & Transformations
[01] B \gets rows(Z), \quad K \gets cols(Z)
[02] P \gets new Matrix of shape (B, K), \quad lse\_vec \gets new Array of size B
[03] b \gets 1 bf to B
[04] m \gets \max_k=1^K (Z[b][k] / T)
[05] S \gets \sum_k=1^K \exp(Z[b][k] / T - m)
[06] lse \gets m + \ln(S)
[07] lse\_vec[b] \gets lse
[08] k \gets 1 bf to K
