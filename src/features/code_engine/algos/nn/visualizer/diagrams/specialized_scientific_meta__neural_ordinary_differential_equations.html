Neural Ordinary Differential Equations

Let $\mathbf{h}(t) \in \mathbb{R}^D$ denote a continuous hidden state trajectory parameterized by continuous depth coordinate $t \in [t_0, t_1]$. A <strong>Neural Ordinary Differential Equation (Neural ODE)</strong> replaces discrete residual layer transitions with a continuous vector field parameterized by neural network $f(\mathbf{h}(t), t; \theta)$: {\boldmath
◈ PRIMARY MATHEMATICAL FORMULATION & DYNAMIC FLOW KaTeX Verified · Closed-Form
$$\frac{\mathrm{d}\mathbf{h}(t)}{\mathrm{d}t} = f(\mathbf{h}(t), t; \theta), \quad \mathbf{h}(t_1) = \mathbf{h}(t_0) + \int_{t_0}^{t_1} f(\mathbf{h}(t), t; \theta) \mathrm{d}t = \operatorname{ODESolve}(\mathbf{h}(t_0), f, t_0, t_1, \theta)$$

◈ Algorithmic Execution Pipeline
ALGORITHM Fourth-Order Runge-Kutta (RK4) Discrete ODE Integration Step
Require: State $\mathbf{h} \in \mathbb{R}^D$, slopes $\mathbf{k}_1, \mathbf{k}_2, \mathbf{k}_3, \mathbf{k}_4 \in \mathbb{R}^D$, step size $\Delta t > 0$
Ensure: Integrated state $\mathbf{h}_{\text{next}} \in \mathbb{R}^D$, effective drift $\bar{\mathbf{k}} \in \mathbb{R}^D$, displacement norm $\|\Delta \mathbf{h}\|_2$
1 Initialize empty arrays $\mathbf{h}_{\text{next}}, \bar{\mathbf{k}}$ of length $D$
2 $disp\_sq \gets 0.0, \quad inv\_six \gets 1.0 / 6.0$
3 for $d = 0$ \textbf{to} $D - 1$ do
4 $drift \gets inv\_six \cdot (\mathbf{k}_1[d] + 2.0 \cdot \mathbf{k}_2[d] + 2.0 \cdot \mathbf{k}_3[d] + \mathbf{k}_4[d])$
5 $disp \gets \Delta t \cdot drift$
6 $disp\_sq \gets disp\_sq + disp \cdot disp$
7 $\bar{\mathbf{k}}[d] \gets drift$
8 $\mathbf{h}_{\text{next}}[d] \gets \mathbf{h}[d] + disp$
9 return $(\mathbf{h}_{\text{next}}, \bar{\mathbf{k}}, \sqrt{disp\_sq})$

★ Theoretical Guarantees & Invariant Bounds
Pontryagin's Adjoint State Dynamics for Neural ODEs
Let $\mathcal{L}(\mathbf{h}(t_1))$ be a scalar loss function evaluated on terminal state $\mathbf{h}(t_1)$, where $\mathbf{h}(t)$ evolves via $\frac{\mathrm{d}\mathbf{h}}{\mathrm{d}t} = f(\mathbf{h}(t), t; \theta)$. Then the adjoint state $\mathbf{a}(t) = \frac{\partial \mathcal{L}}{\partial \mathbf{h}(t)}$ satisfies the continuous differential equation: $$ \frac{\mathrm{d}\mathbf{a}(t)}{\mathrm{d}t} = -\mathbf{a}(t)^T \frac{\partial f(\mathbf{h}(t), t; \theta)}{\partial \mathbf{h}(t)} $$ with terminal boundary condition $\mathbf{a}(t_1) = \frac{\partial \mathcal{L}}{\partial \mathbf{h}(t_1)}$.
Order of Local and Global Error for RK4 Integration
Assume $f(\mathbf{h}, t)$ is four times continuously differentiable ($\mathcal{C}^4$) with Lipschitz constant $L$. The local truncation error of the classical RK4 step is $\mathcal{O}(\Delta t^5)$, and the accumulated global error over interval $[t_0, t_1]$ is $\mathcal{O}(\Delta t^4)$.
⚙ Asymptotic Complexity & Hardware Target
▸ Time Complexity: $\mathcal{O}(N)$ FLOPs per layer forward execution.
▸ Space Complexity: $\mathcal{O}(N)$ auxiliary memory buffers for intermediate activations.
