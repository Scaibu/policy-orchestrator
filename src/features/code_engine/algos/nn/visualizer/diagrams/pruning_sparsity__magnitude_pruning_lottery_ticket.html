Pruning Sparsity

Magnitude Pruning Lottery Ticket

Modern deep neural networks contain billions of parameters, exhibiting massive overparameterization. The <strong>Lottery Ticket Hypothesis (LTH)</strong> (Frankle \& Carbin, 2019) conjectures that a randomly initialized, dense feedforward network $f(x; \theta_0)$ with $\theta_0 \sim \mathcal{D}_\theta$ contains a sparse subnetwork $f(x; m \odot \theta_0)$, parameterized by a binary mask $m \in \{0, 1\}^P$ ($m \odot \theta \triangleq (m_1 \theta_1, \dots, m_P \theta_P)$), that can be trained in isolation to achieve test accuracy comparable to the original dense network within at most the same number of training iterations. The sparse mask $m$ is discovered via <strong>Iterative Magnitude Pruning (IMP)</strong> with weight rewinding: \begin{enumerate} \item Train the dense network from initialization $\theta_0$ (or early warmup checkpoint $\theta_k$, $k \ge 0$) to convergence $\theta_T$. \item Compute parameter saliencies by absolute magnitude: $s_i \triangleq |\theta_{T, i}|$. \item Determine the pruning cutoff threshold $\tau_s$ at desired sparsity quantile $s \in [0, 1)$: {\boldmath

$$\tau_s \triangleq \inf\left\{ \tau \in \mathbb{R}_+ : \frac{1}{P} \sum_{i=1}^P \mathbf{1}\left( |\theta_{T, i}| \le \tau \right) \ge s \right\}$$

◈ Algorithmic Execution Pipeline
ALGORITHM Iterative Magnitude Pruning with Weight Rewinding
Require: Current weights $\boldsymbol{\theta} \in \mathbb{R}^P$, initial weights $\boldsymbol{\theta}_0 \in \mathbb{R}^P$, target sparsity $s \in [0, 1)$, rewind flag $\mathcal{R}$
Ensure: Pruned weights $\boldsymbol{\theta}' \in \mathbb{R}^P$, binary mask $\mathbf{m} \in \{0, 1\}^P$, achieved sparsity $s_{\text{ach}}$, threshold $\tau$, surviving count $P_{\text{surv}}$
1 $P \gets \operatorname{len}(\boldsymbol{\theta})$
2 if $s = 0$ then
3 return $(\boldsymbol{\theta}_0 \text{ if } \mathcal{R} \text{ else } \boldsymbol{\theta}, [1]^P, 0.0, 0.0, P)$
4 $K \gets \operatorname{clip}(\lfloor s \cdot P \rfloor, 0, P - 1)$
5 Sort parameter indices by magnitude: $\boldsymbol{\pi} \gets \operatorname{argsort}([|\theta_i| \text{ for } i \in [0, P-1]])$
6 $\mathcal{I}_{\text{prune}} \gets \operatorname{Set}(\boldsymbol{\pi}[0 : K])$
7 $\tau \gets |\boldsymbol{\theta}[\boldsymbol{\pi}[K]]|$
8 Initialize $\mathbf{m} \gets [\,], \quad \boldsymbol{\theta}' \gets [\,], \quad P_{\text{surv}} \gets 0$
9 for $i = 0$ \textbf{to} $P - 1$ do
10 if $i \in \mathcal{I}_{\text{prune}}$ then
11 Append $0$ to $\mathbf{m}$
12 Append $0.0$ to $\boldsymbol{\theta}'$
13 else
14 Append $1$ to $\mathbf{m}$
15 Append $\boldsymbol{\theta}_0[i]$ if $\mathcal{R}$ else $\boldsymbol{\theta}[i]$ to $\boldsymbol{\theta}'$
16 $P_{\text{surv}} \gets P_{\text{surv}} + 1$
17 $s_{\text{ach}} \gets (P - P_{\text{surv}}) / P$
18 return $(\boldsymbol{\theta}', \mathbf{m}, s_{\text{ach}}, \tau, P_{\text{surv}})$

★ Theoretical Guarantees & Invariant Bounds
Exact Sparsity Guarantee of Magnitude Quantile Pruning
Let $\theta \in \mathbb{R}^P$ be a continuous parameter vector with distinct absolute values $|\theta_1| < \dots < |\theta_P|$. For any target sparsity $s \in [0, 1)$, let $K = \lfloor s \cdot P \rfloor$ denote the number of weights to prune. If the pruning threshold is chosen as $\tau = |\theta_{\pi(K)}|$ where $\pi$ is the sorting permutation $|\theta_{\pi(1)}| \le \dots \le |\theta_{\pi(P)}|$, the achieved empirical sparsity $s_{\text{achieved}} \triangleq \frac{1}{P} \sum_{i=1}^P (1 - m_i)$ satisfies: $$ s_{\text{achieved}} = \frac{\lfloor s \cdot P \rfloor}{P} \in \left[ s - \frac{1}{P}, \, s \right] $$
First-Order Loss Taylor Perturbation from Magnitude Pruning
Let $\mathcal{L}(\theta)$ be a twice continuously differentiable loss function. Expanding $\mathcal{L}$ about the trained parameter point $\theta_T$ where $\nabla \mathcal{L}(\theta_T) \approx \mathbf{0}$, the increase in loss resulting from zeroing pruned parameters $\Delta \theta = m \odot \theta_T - \theta_T$ is bounded by: $$ \Delta \mathcal{L} \approx \frac{1}{2} \sum_{i \in \mathcal{I}_{\text{prune}}} H_{ii} \theta_{T, i}^2 + \mathcal{O}\left( \max_{i \in \mathcal{I}_{\text{prune}}} |\theta_{T, i}|^3 \right) $$ where $H = \nabla^2 \mathcal{L}(\theta_T)$ is the Hessian matrix.
