Phase 5: Post-Training Dual-Track Alignment & Verifiable Reasoning

Track A: Bradley-Terry reward modeling → RLHF PPO with adaptive KL penalty → DPO/SimPO/KTO. Track B: Group rollout sampling → Python/Sympy sandbox verification → GRPO critic-free advantages → Process Reward Models. TIES/DARE merging unifies both checkpoints.
