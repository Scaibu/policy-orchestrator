Variance Preservation and Orthogonality of the Velocity Target
Let x_0 \sim N(0, I) and \boldsymbolε \sim N(0, I) be mutually independent standard normal vectors.
Exact Algebraic Reconstructibility of Clean Data from Velocity
For any state x_t = \sqrtα_tx_0 + \sqrt1 - α_t\boldsymbolε and velocity v_t = \sqrtα_t\boldsymbolε - \sqrt1 - α_tx_0, the clean state x_0 satisfies the identity: \boldmath \beginequation x_0 \equiv \sqrtα_tx_t - \sqrt1 - α_tv_t \endequation without error.
