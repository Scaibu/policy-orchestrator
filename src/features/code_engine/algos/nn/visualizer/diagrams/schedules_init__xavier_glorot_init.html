ALGORITHM Xavier / Glorot Initialization Statistics Computation
Require: Fan-in count $n_{\text{in}} \ge 1$, fan-out count $n_{\text{out}} \ge 1$
Require: Distribution family $\in \{\text{uniform}, \text{normal}\}$, gain $\gamma > 0$
Ensure: Standard deviation $\sigma$, uniform bound $a$, variance $\sigma^2$
1 if $n_{\text{in}} < 1$ \textbf{or} $n_{\text{out}} < 1$ \textbf{or} $\gamma \le 0$ then
2 \textbf{throw} PreconditionFailureException(``Invalid fan dimensions or non-positive gain'')
3 $\text{var} \gets (\gamma^2) \cdot \left(\frac{2.0}{\text{float}(n_{\text{in}} + n_{\text{out}})}\right)$
4 $\text{std} \gets \sqrt{\text{var}}$
5 $\text{bound} \gets \sqrt{3.0 \cdot \text{var}}$
6 return $\{\text{std\_dev}: \text{std}, \text{uniform\_bound}: \text{bound}, \text{variance}: \text{var}\}$

★ Theoretical Guarantees & Invariant Bounds
Forward and Backward Variance Balance
Assume input features $x_i$ and weights $W_{ij}$ are mutually independent zero-mean random variables with $\operatorname{Var}(x_i) = \operatorname{Var}(x)$ and $\operatorname{Var}(W_{ij}) = \sigma^2$. For a linear transformation $y_i = \sum_{j=1}^{n_{\text{in}}} W_{ij} x_j$: $$ \operatorname{Var}(y_i) = n_{\text{in}} \sigma^2 \operatorname{Var}(x) $$ and for incoming gradient $\frac{\partial \mathcal{L}}{\partial x_j} = \sum_{i=1}^{n_{\text{out}}} W_{ij} \frac{\partial \mathcal{L}}{\partial y_i}$: $$ \operatorname{Var}\left(\frac{\partial \mathcal{L}}{\partial x_j}\right) = n_{\text{out}} \sigma^2 \operatorname{Var}\left(\frac{\partial \mathcal{L}}{\partial y}\right) $$ Setting $\sigma^2 = \frac{2}{n_{\text{in}} + n_{\text{out}}}$ enforces $\frac{1}{2}\left(n_{\text{in}} \sigma^2 + n_{\text{out}} \sigma^2\right) = 1.0$, preserving average signal energy.
⚙ Asymptotic Complexity & Hardware Target
▸ Time: $\mathcal{O}(1)$ to compute statistics; $\mathcal{O}(n_{\text{in}} \times n_{\text{out}})$ to sample tensor weights.
▸ Space: $\mathcal{O}(1)$ auxiliary memory.
