Pruning Sparsity

Structured Oneshot Pruning Llms

In modern transformer-based Large Language Models (LLMs), post-training retraining or iterative fine-tuning across billions of tokens is prohibitively compute-expensive. Traditional post-training pruning techniques fail catastrophically: unweighted magnitude pruning collapses language generation perplexity at modest 50\% sparsity because LLM activations exhibit extreme emergent <strong>outlier features</strong> (Dettmers et al., 2022) with magnitudes up to 100 times larger than standard channels. <strong>Wanda</strong> (Pruning by <strong>W</strong>eights <strong>and</strong> <strong>A</strong>ctivations) (Sun et al., 2023) performs one-shot post-training pruning without weight retraining by factoring input activation statistics directly into the importance metric. Given a linear weight projection matrix $\mathbf{W} \in \mathbb{R}^{d_{\text{out}} \times d_{\text{in}}}$ and calibration input feature activations $\mathbf{X} \in \mathbb{R}^{N \times d_{\text{in}}}$, the column-wise $L_2$-norm vector of input features is: {\boldmath
◈ PRIMARY MATHEMATICAL FORMULATION & DYNAMIC FLOW KaTeX Verified · Closed-Form
$$\|\mathbf{X}_j\|_2 \triangleq \sqrt{\sum_{k=1}^N X_{k, j}^2}, \quad \forall j \in \{1, \dots, d_{\text{in}}\}$$

◈ Algorithmic Execution Pipeline
ALGORITHM One-Shot Structured Pruning for LLMs (Wanda)
Require: Weight matrix $\mathbf{W} \in \mathbb{R}^{d_{\text{out}} \times d_{\text{in}}}$, activation norms $\mathbf{a} \in \mathbb{R}^{d_{\text{in}}}$, ratio $r \in [0, 1)$, mode $\in \{\text{"wanda"}, \text{"magnitude"}\}$
Ensure: Pruned matrix $\mathbf{W}' \in \mathbb{R}^{d_{\text{out}} \times d_{\text{in}}}$, score matrix $\mathbf{S}$, achieved sparsity $s_{\text{ach}}$, zeroed count $N_{\text{zero}}$
1 $d_{\text{out}} \gets \operatorname{len}(\mathbf{W}), \quad d_{\text{in}} \gets \operatorname{len}(\mathbf{a})$
2 $k_{\text{prune}} \gets \lfloor r \cdot d_{\text{in}} \rfloor$
3 Initialize $\mathbf{W}' \gets [\,], \quad \mathbf{S} \gets [\,], \quad N_{\text{zero}} \gets 0$
4 for $i = 0$ \textbf{to} $d_{\text{out}} - 1$ do
5 Initialize row scores $\mathbf{s}_i \gets [\,]$
6 for $j = 0$ \textbf{to} $d_{\text{in}} - 1$ do
7 if mode $=$ "magnitude" then
8 Append $|W_{ij}|$ to $\mathbf{s}_i$
9 else
10 Append $|W_{ij}| \cdot a_j$ to $\mathbf{s}_i$
11 Append $\mathbf{s}_i$ to $\mathbf{S}$
12 if $k_{\text{prune}} > 0$ then
13 $\boldsymbol{\pi}_i \gets \operatorname{argsort}(\mathbf{s}_i)$
14 $\mathcal{P}_i \gets \operatorname{Set}(\boldsymbol{\pi}_i[0 : k_{\text{prune}}])$
15 Append $[ 0.0 \text{ if } j \in \mathcal{P}_i \text{ else } W_{ij} \text{ for } j \in [0, d_{\text{in}}-1] ]$ to $\mathbf{W}'$
16 $N_{\text{zero}} \gets N_{\text{zero}} + k_{\text{prune}}$
17 else
18 Append $\mathbf{W}[i]$ to $\mathbf{W}'$
19 $s_{\text{ach}} \gets N_{\text{zero}} / (d_{\text{out}} \cdot d_{\text{in}})$
20 return $(\mathbf{W}', \mathbf{S}, s_{\text{ach}}, N_{\text{zero}}, d_{\text{out}} \cdot d_{\text{in}})$

★ Theoretical Guarantees & Invariant Bounds
Minimization of Output Layer Perturbation Bound
For a linear layer $\mathbf{y}_i = \sum_{j=1}^{d_{\text{in}}} W_{ij} \mathbf{x}_j$, let $\mathcal{P}_i \subset \{1, \dots, d_{\text{in}}\}$ be the set of pruned column indices with cardinality $|\mathcal{P}_i| = k$. The Wanda pruning strategy that selects $\mathcal{P}_i^* = \operatorname{argmin}_{|\mathcal{P}_i|=k} \sum_{j \in \mathcal{P}_i} |W_{ij}| \cdot \|\mathbf{x}_j\|_2$ minimizes the uniform Cauchy-Schwarz upper bound on the output error magnitude $\|\Delta \mathbf{y}_i\|_2$: $$ \left\| \Delta \mathbf{y}_i \right\|_2 \le \sum_{j \in \mathcal{P}_i^*} S_{ij} \le \sum_{j \in \mathcal{P}_i} S_{ij}, \quad \forall \, \mathcal{P}_i \text{ s.t. } |\mathcal{P}_i| = k $$
Failure of Pure Magnitude Pruning Under Activation Outliers
Assume input channel $k$ contains an emergent activation outlier feature such that $\|\mathbf{X}_k\|_2 = M \gg 1$, while for all other channels $j \neq k$, $\|\mathbf{X}_j\|_2 \le 1$. Suppose weight $|W_{ik}| = \epsilon > 0$ is small such that $|W_{ik}| < |W_{ij}|$ for all $j \neq k$, but $\epsilon M > \max_j |W_{ij}|$. Then: \begin{enumerate} \item Pure magnitude pruning prunes coordinate $k$, incurring an error bound $\Delta_{\text{mag}} = \epsilon M \gg 1$. \item Wanda preserves coordinate $k$, selecting coordinate $j^*$ with error $\Delta_{\text{wanda}} = |W_{ij^*}| \le \max_j |W_{ij}| \ll \epsilon M$. \end{enumerate}
