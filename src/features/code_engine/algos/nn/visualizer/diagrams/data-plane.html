Data Plane: 5D Distributed Messaging Fabric & Transformer Layer Forward/Backward

Five orthogonal communication planes: NVLink All-Reduce TP, InfiniBand Ring CP, InfiniBand P2P PP, All-to-All EP, and ZeRO-3 memory mesh. Simple forward/backward walkthrough shows how words become smarter representations through attention and MoE lookup.

    subgraph ForwardPass ["1. Forward Pass: Processing Words into Smarter Meanings"]
        WordInputs["Input Word Representations"]:::input --> CleanNumbers["1. Normalize Values with RMSNorm"]:::step
        CleanNumbers --> AddPositions["2. Add Word Order with RoPE"]:::step
        AddPositions --> AttentionCompare["3. Multi-Head Attention - Lets words look at and compare each other"]:::step
        AttentionCompare --> CombineAttn["4. Combine Attention Output - Puts all head discoveries back together"]:::step
        CombineAttn --> AddSkip1["5. Add Skip Connection - Adds input back so model never forgets"]:::step
        AddSkip1 --> CleanNumbers2["6. Second Normalization RMSNorm"]:::step
        CleanNumbers2 --> ExpertLookup["7. Feed-Forward Expert Networks MLP MoE - Looks up facts and deeper concepts"]:::step
        ExpertLookup --> AddSkip2["8. Second Skip Connection"]:::step
        AddSkip2 --> WordOutputs["Output Representations Ready for Next Layer"]:::input
    end

    subgraph BackwardPass ["2. Backward Pass: Learning from Mistakes"]
        LossError["Calculate Error at Output - How wrong was the model's guess?"]:::learn --> SendBackErrors["Send Gradients Backward - Reverse-mode autodiff calculates each step's blame"]:::learn
        SendBackErrors --> SyncAcrossGPUs["Synchronize Gradients Across GPUs"]:::network
        SyncAcrossGPUs --> UpdateWeights["Update Weights with AdamW"]:::learn
    end
