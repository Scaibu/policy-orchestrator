Deep Interest Network Attention

Let _A ^D denote the embedding vector of a candidate ad or item to be scored, and let = _1, _2, , _H denote a user's historical behavior sequence of H previously interacted items, each represented by ...
◈ Input Tensors & Parameter Arrays
● Candidate embedding v_A \in \mathbbR^D
● history embeddings E \in \mathbbR^H \times D
● attention weights W_1 \in \mathbbR^D_attn \times 4D
● b_1 \in \mathbbR^D_attn
● w_2 \in \mathbbR^D_attn
● bias b_2 \in \mathbbR
◈ Execution Lifecycle & Transformations
[01] Initialize raw scores s \in \mathbbR^H
[02] i = 0 bfto H-1 \CommentEvaluate Local Activation Units
[03] e_i \gets E[i]
[04] I \gets [e_i; \; v_A; \; e_i \odot v_A; \; e_i - v_A] \in \mathbbR^4D
[05] Initialize hidden vector h \in \mathbbR^D_attn
[06] j = 0 bfto D_attn-1
[07] val \gets \sum_k=0^4D-1 W_1[j][k] \cdot I[k] + b_1[j]
[08] h[j] \gets \max(0.0, val)
◈ Computed Outputs & Target Signals
■ User interest vector v_U \in \mathbbR^D
■ attention weights w \in \mathbbR^H
■ total mass M
■ dominant item index i^*
