◈ Algorithmic Execution Pipeline
ALGORITHM ResNet Residual Block Forward Pass
Require: Input $X \in \mathbb{R}^{C_{\text{in}} \times H_{\text{in}} \times W_{\text{in}}}$, topology $T \in \{\text{basic}, \text{bottleneck}\}$, weights $(\mathcal{W}_1, \mathcal{W}_2, \mathcal{W}_3)$, shortcut $\mathcal{W}_s$, stride $s$.
Ensure: Output tensor $Y \in \mathbb{R}^{C_{\text{out}} \times H_{\text{out}} \times W_{\text{out}}}$, residual $F_{\text{out}}$, shortcut $S_{\text{out}}$.
1 if $T = \text{basic}$ then
2 $Z_1 \gets \text{Conv2D}(X, \mathcal{W}_1, \text{stride}=s, \text{pad}=1)$
3 $A_1 \gets \text{ReLU}(Z_1)$
4 $F_{\text{out}} \gets \text{Conv2D}(A_1, \mathcal{W}_2, \text{stride}=1, \text{pad}=1)$
5 else
6 $Z_1 \gets \text{Conv2D}(X, \mathcal{W}_1, \text{stride}=1, \text{pad}=0)$
7 $A_1 \gets \text{ReLU}(Z_1)$
8 $Z_2 \gets \text{Conv2D}(A_1, \mathcal{W}_2, \text{stride}=s, \text{pad}=1)$
9 $A_2 \gets \text{ReLU}(Z_2)$
10 $F_{\text{out}} \gets \text{Conv2D}(A_2, \mathcal{W}_3, \text{stride}=1, \text{pad}=0)$
11 if $\mathcal{W}_s$ is provided then
12 $S_{\text{out}} \gets \text{Conv2D}(X, \mathcal{W}_s, \text{stride}=s, \text{pad}=0)$
13 else
14 $S_{\text{out}} \gets \text{IdentitySubsample}(X, s)$
15 $Y \gets \text{ReLU}(F_{\text{out}} + S_{\text{out}})$
16 return $\{Y, F_{\text{out}}, S_{\text{out}}\}$

★ Theoretical Guarantees & Invariant Bounds
Unimpeded Gradient Flow in Residual Networks
Let an $L$-layer network be defined by the clean residual recurrence $x_{l+1} = x_l + \mathcal{F}(x_l; \mathcal{W}_l)$. For any shallow layer $l$ and deep layer $L$, the gradient of loss $\mathcal{E}$ satisfies: $$ \frac{\partial \mathcal{E}}{\partial x_l} = \frac{\partial \mathcal{E}}{\partial x_L} \left( I + \frac{\partial}{\partial x_l} \sum_{i=l}^{L-1} \mathcal{F}(x_i; \mathcal{W}_i) \right) $$ guaranteeing that the gradient $\frac{\partial \mathcal{E}}{\partial x_l}$ never vanishes even if $\frac{\partial \mathcal{F}}{\partial x_i}$ is arbitrarily small.
