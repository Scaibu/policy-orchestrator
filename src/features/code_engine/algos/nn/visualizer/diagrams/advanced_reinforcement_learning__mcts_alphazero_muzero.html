Classical Monte Carlo Tree Search (MCTS) relies on random rollouts to estimate terminal state values, suffering from exponential sample complexity in deep game trees. <strong>AlphaZero and MuZero</strong> replace random rollouts with dual-headed deep neural networks that evaluate state value $v_\theta(s)$ and output prior action probabilities $P_\theta(a | s)$. At each search step from state $s$, action selection follows the <strong>Polynomial Upper Confidence Trees (PUCT)</strong> algorithm: {\boldmath
◈ PRIMARY MATHEMATICAL FORMULATION & DYNAMIC FLOW KaTeX Verified · Closed-Form
$$a^* = \arg\max_{a \in \mathcal{A}} \left[ Q(s, a) + U(s, a) \right]$$

◈ Algorithmic Execution Pipeline
ALGORITHM MCTS PUCT Action Selection and Target Extraction
Require: Prior probabilities $\mathbf{P}$, visit counts $\mathbf{N}$, Q-values $\mathbf{Q}$, $c_{\text{init}}, c_{\text{base}}, \tau$
Ensure: Selected action $a^*$, PUCT scores $\mathbf{S}$, exploration terms $\mathbf{U}$, target policy $\boldsymbol{\pi}$, root value $v_{\text{root}}$
1 $total\_visits \gets \sum_{a=0}^{A-1} \mathbf{N}[a]$
2 $c_{\text{scale}} \gets c_{\text{init}} + \ln((total\_visits + c_{\text{base}} + 1.0) / c_{\text{base}})$
3 $best\_score \gets -\infty, \quad a^* \gets 0$
4 Allocate $\mathbf{S} \in \mathbb{R}^A, \quad \mathbf{U} \in \mathbb{R}^A, \quad \boldsymbol{\pi} \in \mathbb{R}^A$
5 for $a = 0$ \textbf{to} $A-1$ do
6 $u_a \gets c_{\text{scale}} \cdot \mathbf{P}[a] \cdot (\sqrt{total\_visits} / (1.0 + \mathbf{N}[a]))$
7 $\mathbf{U}[a] \gets u_a$
8 $\mathbf{S}[a] \gets \mathbf{Q}[a] + u_a$
9 if $\mathbf{S}[a] > best\_score$ then
10 $best\_score \gets \mathbf{S}[a], \quad a^* \gets a$
11 if $total\_visits == 0$ then
12 $\boldsymbol{\pi} \gets [1/A, \dots, 1/A], \quad v_{\text{root}} \gets \frac{1}{A}\sum_{a=0}^{A-1} \mathbf{Q}[a]$
13 else
14 $sum\_pow \gets \sum_{a=0}^{A-1} (\mathbf{N}[a])^{1/\tau}$
15 for $a = 0$ \textbf{to} $A-1$ do
16 $\boldsymbol{\pi}[a] \gets (\mathbf{N}[a])^{1/\tau} / sum\_pow$
17 $v_{\text{root}} \gets \sum_{a=0}^{A-1} (\mathbf{N}[a] / total\_visits) \cdot \mathbf{Q}[a]$
18 return $(a^*, \mathbf{S}, \mathbf{U}, \boldsymbol{\pi}, v_{\text{root}})$

★ Theoretical Guarantees & Invariant Bounds
Asymptotic Convergence of PUCT to Optimal Minimax Action
For any finite discrete Markov decision process with bounded rewards, as the number of MCTS simulations $M = \sum_a N(s, a) \to \infty$, the probability of selecting an action with suboptimal expected return converges to zero.
Invariance of Uniform Visit Policy Under Temperature Scaling
If the search visit counts are uniformly distributed $N(s, a) = K$ for all $a \in \mathcal{A}$, then the target policy $\pi(a | s) \equiv \frac{1}{|\mathcal{A}|}$ for all valid temperature parameters $\tau > 0$.
⚙ Asymptotic Complexity & Hardware Target
▸ Time Complexity: $\mathcal{O}(N)$ FLOPs per layer forward execution.
▸ Space Complexity: $\mathcal{O}(N)$ auxiliary memory buffers for intermediate activations.
