Require: Input tensor $\mathbf{x} \in \mathbb{R}^d$, hyperparameter set $\mathcal{H}$
Ensure: Optimal processed output $\mathbf{y} \in \mathbb{R}^d$, diagnostic certificate $\mathcal{C}$
1 $\mu \gets \frac{1}{d} \sum_{i=1}^d x_i$
2 $\sigma^2 \gets \frac{1}{d} \sum_{i=1}^d (x_i - \mu)^2$
3 for each channel coordinate $j \in \{1, \dots, d\}$ do
4 Evaluate local transform $\hat{x}_j \gets \phi(x_j, \mu, \sigma, \mathcal{H})$
5 Compute invariant projection $y_j \gets \text{Clamp}(\hat{x}_j, \text{bounds}(\mathcal{H}))$
6 $\mathcal{C} \gets \text{VerifyInvariants}(\mathbf{x}, \mathbf{y})$
7 return $\{\mathbf{y}, \mathcal{C}\}$
