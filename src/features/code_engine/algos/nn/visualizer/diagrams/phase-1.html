§ 1.1.1 Data & Ingestion

Phase 1: Data Ingestion, Mixture Optimization & Packing

DoReMi excess-loss mirror descent reweights domain sampling probabilities. First-Fit Decreasing packing builds 2D block-diagonal causal masks eliminating cross-document leakage.

        WeightedSampler --> DocSequences["Variable-Length Document Sequences"]:::source
        DocSequences --> BinPack["Sequence Packing First-Fit Decreasing, Capacity: max_sequence_length"]:::pack
        BinPack --> SegmentIDs["Generate Segment IDs & Monotonic Position IDs"]:::pack
        BinPack --> MaskGen["2D Block-Diagonal Causal Attention Mask Generator - Zero cross-document attention leakage"]:::pack
    end
