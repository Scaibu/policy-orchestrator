◈ Algorithmic Execution Pipeline
ALGORITHM Long Short-Term Memory Step and Unroll
Require: Sequence $\{\mathbf{x}_t\}_{t=1}^T$, initial states $\mathbf{h}_0 = \mathbf{0}, \mathbf{c}_0 = \mathbf{0}$, weights $\mathbf{W}, \mathbf{U}$, biases $\mathbf{b}$.
Ensure: Hidden state trajectory $\{\mathbf{h}_t\}_{t=1}^T$, cell state trajectory $\{\mathbf{c}_t\}_{t=1}^T$.
1 for $t = 1$ \textbf{to} $T$ do
2 $\mathbf{z} \gets \mathbf{W} \mathbf{x}_t + \mathbf{U} \mathbf{h}_{t-1} + \mathbf{b}$
3 $\mathbf{f}_t \gets \sigma(\mathbf{z}[0 : d_h])$
4 $\mathbf{i}_t \gets \sigma(\mathbf{z}[d_h : 2d_h])$
5 $\tilde{\mathbf{c}}_t \gets \tanh(\mathbf{z}[2d_h : 3d_h])$
6 $\mathbf{o}_t \gets \sigma(\mathbf{z}[3d_h : 4d_h])$
7 $\mathbf{c}_t \gets \mathbf{f}_t \odot \mathbf{c}_{t-1} + \mathbf{i}_t \odot \tilde{\mathbf{c}}_t$
8 $\mathbf{h}_t \gets \mathbf{o}_t \odot \tanh(\mathbf{c}_t)$
9 return $\{\mathbf{h}_t\}_{t=1}^T, \{\mathbf{c}_t\}_{t=1}^T$

★ Theoretical Guarantees & Invariant Bounds
Constant Error Carousel Gradient Preservation
\label{thm:cec_gradient} Let the forget gate be saturated to $\mathbf{f}_k = \mathbf{1}$ for all steps $k \in [t+1, T]$. The temporal gradient of the cell state $\frac{\partial \mathbf{c}_T}{\partial \mathbf{c}_t}$ satisfies: $$ \frac{\partial \mathbf{c}_T}{\partial \mathbf{c}_t} = \prod_{k=t+1}^T \text{diag}(\mathbf{f}_k) = I_{d_h} $$ guaranteeing zero exponential vanishing of error signals along the cell trajectory over arbitrary temporal spans $(T - t)$.
⚙ Asymptotic Complexity & Hardware Target
▸ Time Complexity: $\mathcal{O}(4 \cdot (d_h d_x + d_h^2))$ FLOPs per time step (approximately $4\times$ the parameter and computational cost of a vanilla RNN).
▸ Space Complexity: $\mathcal{O}(2 \cdot d_h)$ memory to store state vectors $(\mathbf{h}_t, \mathbf{c}_t)$.
