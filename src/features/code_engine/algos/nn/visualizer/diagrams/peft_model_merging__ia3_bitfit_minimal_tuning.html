Ia3 Bitfit Minimal Tuning

While Low-Rank Adaptation (LoRA) reduces trainable parameters to approximately $0.1\%\text{--}1\%$, extreme minimal-parameter fine-tuning paradigms such as <strong>IA³</strong> (Liu et al., 2022) and <strong>BitFit</strong> (Zaken et al., 2022) push parameter reduction to the absolute theoretical limit: adapting large neural networks by modifying fewer than $0.01\%$ (in the case of IA³) or $0.1\%$ (BitFit) of the total parameter count. \begin{enumerate} \item <strong>IA³ (Infused Adapter by Inhibiting and Amplifying Inner Activations)</strong>: IA³ freezes all pretrained weights and introduces learnable scalar vectors $l \in \mathbb{R}^d$ that rescale intermediate activations via elementwise (Hadamard) multiplication: {\boldmath

★ Theoretical Guarantees & Invariant Bounds
Commutativity and Exact Inference Folding of IA³
Let $W_0 \in \mathbb{R}^{d \times k}$ be a linear projection matrix and $x \in \mathbb{R}^k$ be an arbitrary input vector. For any learned scaling vector $l \in \mathbb{R}^d$, the operation $y = l \odot (W_0 x)$ is mathematically equivalent to multiplying $x$ by a modified weight matrix $W_{\text{fused}}$: $$ l \odot (W_0 x) \equiv W_{\text{fused}} x $$ where row $i$ of $W_{\text{fused}}$ is given by $(W_{\text{fused}})_{i,:} = l_i \cdot (W_0)_{i,:}$.
BitFit Representation Shift as Subspace Translation
Let $\mathcal{F}_{\Theta_0}(x)$ be a deep neural network whose intermediate linear representations are $h_l = W_l a_{l-1} + b_l$. Tuning exclusively the biases $\{b_l\}$ preserves the directional orientation of all neuron feature hyperplanes while enabling arbitrary parallel translations: $$ \{ x \mid W_l x + b_l' = 0 \} \parallel \{ x \mid W_l x + b_l = 0 \} $$
