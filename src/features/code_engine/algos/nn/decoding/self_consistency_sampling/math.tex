\begin{abstract}
Complex multi-step reasoning problems suffer from stochastic failures when using greedy decoding. Self-Consistency samples $N$ diverse reasoning paths with temperature $T > 0$ and selects the final answer by majority vote across normalized terminal answers. This specification formalizes the plurality vote operator, statistical error bounds, and numerical verification.
\end{abstract}

\section{Mathematical Formulation}

Let sampled answer strings be $\{a_1, a_2, \dots, a_N\}$. The ensemble consensus answer is:
\begin{equation}
\hat{a} = \arg\max_{a} \sum_{i=1}^N \mathbb{I}(\operatorname{Normalize}(a_i) = a)
\end{equation}
