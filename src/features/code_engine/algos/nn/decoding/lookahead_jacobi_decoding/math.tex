\begin{abstract}
Autoregressive decoding is inherently serial. Lookahead (Jacobi) decoding formulates multi-token generation as solving a system of non-linear fixed-point equations in parallel. An $n$-token candidate window is updated simultaneously across all positions using Jacobi iterations until numerical convergence $x_t^{(k+1)} = x_t^{(k)}$. This specification formalizes the Jacobi fixed-point mapping and convergence dynamics.
\end{abstract}

\section{Fixed-Point Formulation}

For window tokens $\mathbf{x} = (x_1, \dots, x_W)$, the simultaneous Jacobi iteration satisfies:
\begin{equation}
x_t^{(k+1)} = \arg\max_v P_\theta\left(v \;\Big|\; x_1^{(k)}, \dots, x_{t-1}^{(k)}\right)
\end{equation}
Iterating continues until $\mathbf{x}^{(k+1)} = \mathbf{x}^{(k)}$ or iteration limit $K$ is reached.
