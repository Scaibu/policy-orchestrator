\begin{abstract}
Constrained Grammar Decoding enforces structured generation (such as valid JSON, SQL, or compiler ASTs) by coupling language model decoding with deterministic finite automata (DFA) or context-free parsers. At each decoding step, the grammar state identifies the valid allowed token set $\mathcal{A} \subset \mathcal{V}$ and masks invalid logits to $-\infty$. This specification formalizes logit masking and language containment guarantees.
\end{abstract}

\section{Mathematical Formulation}

Given current parse state $q \in Q$ and vocabulary $\mathcal{V}$, the transition function defines allowed tokens:
\begin{equation}
\mathcal{A}(q) = \{ v \in \mathcal{V} \mid \delta(q, v) \ne \emptyset \}
\end{equation}
Logit masking:
\begin{equation}
\tilde{z}_v = \begin{cases} z_v, & \text{if } v \in \mathcal{A}(q) \\ -\infty, & \text{if } v \notin \mathcal{A}(q) \end{cases}
\end{equation}
