\begin{abstract}
Contrastive Search balances model confidence with a degeneration penalty that measures the isotropic cosine similarity between candidate hidden representations and prior context vectors. This specification formalizes the dual-objective score function, proving repulsion from repetitive attractors.
\end{abstract}

\section{Mathematical Formulation}

For top-$k$ candidates $v \in \mathcal{V}^{(k)}$:
\begin{equation}
\operatorname{Score}(v) = (1 - \alpha) P_\theta(v \mid \mathbf{x}_{<t}) - \alpha \max_{1 \le j < t} \frac{\mathbf{h}_v^\top \mathbf{h}_j}{\|\mathbf{h}_v\|_2 \|\mathbf{h}_j\|_2}
\end{equation}
where $\alpha \in [0, 1]$ governs the trade-off between model probability and representation diversity.
