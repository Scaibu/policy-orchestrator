\begin{abstract}
Speculative decoding typically requires hosting two separate models. Medusa attaches multiple lightweight parameter heads directly to the primary transformer's final hidden state, predicting future tokens simultaneously and assembling candidate trajectories into a tree structure evaluated in parallel via tree-masked attention.
\end{abstract}
