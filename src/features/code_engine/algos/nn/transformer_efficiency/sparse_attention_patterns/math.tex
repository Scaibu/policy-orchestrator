\begin{abstract}
Sparse Attention decomposes the full dense attention connectivity graph into a union of three structured subgraphs: sliding local windows, global memory landmarks, and pseudo-random expander edges. This document formalizes the tripartite graph adjacency matrix, proves graph diameter bounds, and details numerical sparsity verification.
\end{abstract}

\section{Notation and Mathematical Preliminaries}

Let $N \in \mathbb{N}_{\ge 1}$ denote sequence length. The sparse adjacency mask $\mathbf{A} \in \{0, 1\}^{N \times N}$ is the union of three connectivity sets:
\begin{equation}
A_{i, j} = \mathbb{I}\left( |i - j| \le w \;\lor\; i \in \mathcal{G} \;\lor\; j \in \mathcal{G} \;\lor\; (i, j) \in \mathcal{R} \right)
\end{equation}
where $w$ is the local window radius, $\mathcal{G}$ is the set of global landmark tokens, and $\mathcal{R}$ denotes pseudo-random edges.

\section{Complexity and Sparsity Analysis}
The total edges scale as $|E| = \mathcal{O}(N(w + |\mathcal{G}| + r))$.
The sparsity ratio is defined by:
\begin{equation}
\text{Sparsity} = 1.0 - \frac{|E|}{N^2}
\end{equation}
approaching $1.0$ as $N \to \infty$.
