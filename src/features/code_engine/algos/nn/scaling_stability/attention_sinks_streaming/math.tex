\begin{abstract}
Deploying autoregressive language models in streaming settings where sequence length exceeds pre-training horizons causes catastrophic perplexity explosion when using naive sliding-window KV caches. StreamingLLM showed this instability originates from the loss of attention sinks: the first few tokens ($S \approx 4$) collect enormous baseline attention weights necessary for softmax partition sum stabilization. Retaining the first $S$ initial tokens alongside the local sliding window of $W$ tokens enables infinite streaming inference with stable perplexity.
\end{abstract}

\section{Notation and Mathematical Preliminaries}

Let token stream $\mathbf{x} = (x_0, x_1, \dots, x_{T-1})$ have length $T > S + W$, where $S \in \mathbb{N}_{\ge 1}$ is the sink token count and $W \in \mathbb{N}_{\ge 1}$ is the local window size.

\begin{equation}
\mathbf{x}_{\text{cached}} = [x_0, \dots, x_{S-1}] \cup [x_{T-W}, \dots, x_{T-1}]
\end{equation}
