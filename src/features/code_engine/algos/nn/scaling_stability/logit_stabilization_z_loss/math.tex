\begin{abstract}
Cross-entropy loss is shift-invariant with respect to logits: adding an arbitrary constant scalar $c \in \mathbb{R}$ to all logits leaves softmax output probabilities unchanged ($\operatorname{softmax}(\mathbf{z} + c) = \operatorname{softmax}(\mathbf{z})$). In low-precision floating point (such as BF16 or FP16), unconstrained logit drift causes logits to grow arbitrarily large, producing roundoff errors, unstable gradients, and catastrophic training loss spikes. Auxiliary logit $z$-loss penalizes squared log-sum-exp values, anchoring logits near zero.
\end{abstract}

\section{Mathematical Formulation}

For batch size $B$ and vocabulary size $V$, the auxiliary $z$-loss is defined as:
\begin{equation}
\mathcal{L}_z = \alpha \frac{1}{B} \sum_{i=1}^B \left( \log \sum_{j=1}^V \exp(z_{i, j}) \right)^2
\end{equation}
where $\alpha \in \mathbb{R}_{> 0}$ is a small weighting hyperparameter (typically $\alpha = 10^{-4}$).

\section{Analytic Gradient Derivation}
Differentiating with respect to logit coordinate $z_{i, k}$:
\begin{equation}
\frac{\partial \mathcal{L}_z}{\partial z_{i, k}} = 2 \alpha \frac{1}{B} \left( \log \sum_{j=1}^V \exp(z_{i, j}) \right) \cdot \operatorname{softmax}(\mathbf{z}_i)_k
\end{equation}
This exerts a continuous inward centering pressure pulling large logits back toward zero.
