\begin{abstract}
Standard Vision Transformers suffer from quadratic computational complexity $\mathcal{O}((HW)^2)$ relative to image resolution. Swin Transformer establishes linear complexity $\mathcal{O}(HW)$ by computing self-attention within non-overlapping local windows and introducing cross-window connectivity via shifted window partitions in alternating layers. This specification formalizes regular and shifted window partitioning, complexity bounds, and numerical verification.
\end{abstract}

\section{Notation and Mathematical Preliminaries}

Let feature map $\mathbf{X} \in \mathbb{R}^{H \times W \times C}$ have height $H$, width $W$, and channels $C$. Let window size be $M \times M$, and shift size be $S \in \{0, \lfloor M/2 \rfloor\}$.

\section{Complexity Comparison}
For an image with $h \times w$ patches:
\begin{itemize}
    \item Standard global attention: $\Omega(4hw C^2 + 2(hw)^2 C)$ (quadratic in image area).
    \item Swin window attention: $\Omega(4hw C^2 + 2 M^2 hw C)$ (strictly linear in image area $hw$ for fixed $M=7$).
\end{itemize}
