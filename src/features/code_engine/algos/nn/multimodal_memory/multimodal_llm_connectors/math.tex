\begin{abstract}
Multimodal Large Language Models connect frozen vision backbones to LLMs using projection layers (linear projectors or multi-layer perceptrons). The connector maps vision token sequences from visual embedding dimension $d_v$ into language model embedding space $d_{\text{llm}}$. This specification formalizes the projection operator, dimensionality bounds, and numerical verification.
\end{abstract}

\section{Mathematical Formulation}

Given vision tokens $\mathbf{V} \in \mathbb{R}^{P \times d_v}$ and projection matrix $\mathbf{W} \in \mathbb{R}^{d_v \times d_{\text{llm}}}$:
\begin{equation}
\mathbf{H}_{\text{llm}} = \mathbf{V} \mathbf{W} + \mathbf{b}
\end{equation}
